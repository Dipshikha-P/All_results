There are 5 folders in this folder. Each folder corresponds to one analysis. 2 machine learning models have been used in this paper, Random Forest classifier and Random Forest regressor. In both cases, the models have been tested progressively, so we have seperate results for each participant. To better understand these results, many types of analysis have been done, such as individual line graphs have been drawn with classification and regression results, saddle point has been generated to understand how quickly the classification model stabilises to the correct predictions. Mean absolute error has been used to check which model training strategy predict the remaining gameplay behaviour better. Finally, standard deviation value has been used to show the difference between 2 types of Solvers and 2 types of Nonsolvers. All these results are organised in different folders. Moreover we used 8 differeny=t data preparation windows to generate the gaze behaviour data and for cross validate the model 10 different test sets were used. The resulting plots are organised based on these.

There are 2 separate folders for individual line graphs according to the models, "Individual classification graphs" and "individual regression graphs". Within these folder, there is a separate folder for each data preparation window and within it, there are 10 separate test set folders in which the graphs are arranged according to the subcategories, i.e., Expert, Persistent, Trier, Quitter

The saddle points and mean absolute errors are analysed in two ways, individually for each participant and each test set, and collectively by combining the values of all the test sets in a box plots so that the average behavior can be analyzed. For this, there is an individual folder inside these 2 folders and a summary folder. Inside these folders, there is a figure for each data preparation window, in which all the test sets are combined.

Again, the random forest regressor has been trained and tested in a 4 separate way, and the folder "Mean absolute error values" is divided accordingly. Inside these folders, there is a figure for each data preparation window, in which all the test sets are combined.

Finally, the standard deviation er results are shown separately for Solvers and Nonsolvers in the folder "Standard deviation of remaining moves".
